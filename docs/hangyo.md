# 半魚文庫テキストの改変記録

元データ：半魚文庫「謡曲三百五十番集」 JALLC TANOMOSHI project No.1
https://hangyo.sakura.ne.jp/utahi/ （yo.lzh、305ファイル・352曲）
配布条件：JALLCフリーデータ配布条件（jgpl1.txt）。著作権は底本校訂者と JALLC が共有（hanrei.txt 6）。

## 改変の内容

改変者：西嶋徹（作業は AI〔Muse／Claude〕を使用）
改変日：2026-11-08

- 文字コードを Shift_JIS（CP932）から UTF-8 に変換
- 見出しタグ（<T> <N> <K> <A> <S> <H>）を取り除き、各ファイル冒頭に「季節・登場・底本・出典」の行として書き直した（同じ情報は manifest.json にも収録）
- ページタグ（<P 128b> など）を除去
- 底本の行どおりの改行を、発言（役名「…）単位の改行に変更。ページの区切りに空行が残っている箇所がある
- 48曲の合本 yoa00.txt を、曲ごとのファイル yoa01.txt〜yoa48.txt に分割
- 曲名タグのない「松虫」「錦木」「船橋」「綾鼓」は、本文1行目の見出しから曲名を補った（manifest.json の title のみ。本文は変えていない）

本文の文字は変えていない。

## 照合結果（2026-11-08）

`scripts/verify_hangyo.py` で、半魚文庫から取り直した yo.lzh と全305ファイル・352曲を照合し、空白・改行・タグを除いた本文が全件一致した。

元データには、書式の崩れたタグ（`<19a>` `<P 213ｃ>` `<k 季冬>` `<A　ツレ>`（全角空白）など）が58行ある。いずれもタグとして除去しており、本文の行ではないことを確認した。

見出し情報のうち、yob03.txt（布留乃能）の `<正花風>` は manifest.json に取り込まれていない。
