## 1 曲の手順

0. 古い切り出し（`.honbun.lines.json` に `x` がない）だと build_kyoku.py が KeyError になる。そのときは `python3 scripts/split_taikan.py <曲名…>` で切り出し直す（第一巻の未確認の曲はまだ古い）。
1. シートを作る: `~/tools/textvenv/bin/python scripts/make_checks.py <曲名>`
   → `work/checks/<曲>/sheetNN.jpg`（赤枠と番号）と `list.txt`。
2. `list.txt` を読み、シートの画像を見て、各番号で大観の印刷とOCR（「大観OCR」欄）を比べる。
   - 印刷どおりなら何もしない（半魚文庫との違いは版の違いなので直さない）。
   - OCR が印刷と違うときだけ記録する。
3. `work/fixes/<曲>.tsv` を書く（**誤りが 0 件でも見出し行だけで作る**。これが「確認済み」の印）:
   ```
   # 頁	OCR	正	備考
   p846	時烏	時鳥	画像で確認
   ```
   字が小さく判別できないものは、備考に「要再確認（高解像度）」と書く。
4. サイト用データを作る: `python3 scripts/build_kyoku.py <曲名>`
   - 「段の番号が飛んでいる」「訂正を当てられなかった」「分量が釣り合わない」と出たら原因を見る。段の印が OCR でどの段にも出ていないときは、原本で位置を確かめて訂正記録で補う（例: `p160	ッレ『東屋の	【三】ツレ『東屋の	段の印の読み落とし`）。
5. 役名を照合する: `~/tools/textvenv/bin/python scripts/role_check.py <曲名>`
   → `work/checks/<曲>/roleNN.jpg` と `roles.txt`。半魚文庫と役名が食い違うもの・読めないもの・行の途中に崩れた役名が残るものが出る。
   - 原本の小字の役名（小段名の上に並ぶ「シテ／ツレ」など）は「シテ・ツレ」と書く。
   - 原本どおりで直さないものも、備考を「役名確認：…」として記録する（照合で再び出ないように）。
   - 本文の位置にあるがト書きの行は、備考を「ト書き：…」で始めるとト書きとして扱う。
   - 要確認が 0 になるまで 4・5 をくり返す。
6. 検索用の読み仮名を `data/yokyoku/taikan_toc.json` のその曲に `"yomi": "たかさご"` の形で足す（現代仮名遣いのひらがな。大観の解説頁の曲名には小さなルビがあるが OCR には出ないので、迷うときは原本のルビも見る）。
   `python3 scripts/fetch_yomi.py <曲名>` で国立国会図書館サーチの謡本の書名の読みを集め（1 曲 1〜2 分）、`work/yomi_ndl.json` の多数決の読みと合っているか確かめる。国立国会図書館は「づ・ぢ」を「ず・じ」と書くので、そこは違ってよい。
7. 一覧を作り直す: `python3 scripts/build_index.py`（読みのない曲があると知らせる）
8. 曲情報・通釈を確かめる（次の節）。梗概の全文照合が済むまで公開しない。

## 曲情報・通釈の確認（2026-11-10 追加。公開の標準手順）

本文は半魚文庫との照合で確かめているが、梗概・人物・通釈・ト書き・間狂言には照合の相手がない。後から目視で見つけるのに頼らず、次の手順を制作の流れに入れる。
誤りは「実在する字への化け」が多く（梅若丸→梅若九、萬葉集→萬葉葉）、辞書では拾えない。同じ曲のほかの所（本文・通釈・人物欄）との食い違いで拾う。

1. **自動で拾う**: `python3 scripts/info_check.py <曲名>`（`build_kyoku.py` の後に実行）
   - 梗概・人物の漢字 2〜4 字が同じ曲のほかの所に出ず、1 字違いの形なら出るもの（梅若九 ↔ 梅若丸）
   - 同じ字が続くもの（萬葉葉）、間違えやすい字の組を含むもの、通釈で 1 回だけの話し手名
   - 読み取りの崩れ（半角の括弧・数字・記号が続く。隅田川 p1525 の「( ) ( ) … (1)2(」）
   - 本文の発言の途中にある役名（鉤括弧の読み落としで次の発言がつながったもの。隅田川 p1532 の「(としをる)ワキうたてやな」。ト書きが混ざった場合も出る）
   - 旧字・異体字は、本文や通釈に同じ形が出れば拾わない（正しい旧字を誤りとして出さない）。互換漢字は文字コードだけの違いなので別に数を出す
2. **文意で判定する**: 拾った箇所と固有名詞（人名・地名・書名）を、一字ずつ「その字で語になるか」「前後の文意と、その曲の筋・人物・所に合うか」で見る。字形が似ているだけでは決めない。判定は理由つきで `work/fixes/<曲>.tsv` の備考に書く。
3. **原本の画像で確定する**: 残った疑わしい箇所は、解説・段の頁の画像で確かめる。直した字は `work/fixes/<曲>.tsv` に書く（再OCR・作り直しで同じ誤りが戻らないように）。曲情報の訂正は解説の頁（曲の最初の頁〜2 頁後）で書けば、`build_kyoku.py` が梗概・人物などに当てる（記録の種類「曲情報」）。
   ```
   p1857	萬葉葉	萬葉集	梗概（解説の頁）。画像で確認（葉／集の取り違え）
   ```
   文意だけで直したものは、備考に「文意で判断。画像は未照合」と書き、画像で確かめたら書き換える。
   手元に作業データがなくても、`python3 scripts/ndl_image.py <曲名> <頁> [x,y,w,h]` で国立国会図書館デジタルコレクションから頁の画像（範囲を % で絞れる）を取れる。
   行ごと読み落とした・崩れた所（罫を括弧や数字に読んだ所など）は、字の訂正では直せない。`work/fixes/<曲>.items.json` に発言単位の差し替えを書くと、`build_kyoku.py` が組み立てた後に当てる（記録の種類「差し替え」。当てられないと警告が出る）。
   ```json
   [{"page": 1525, "dan": 4, "band": "tsushaku", "find": "東路にありやなしやと』( ) ( )",
     "set": {"text": "（原本どおりの全文）"},
     "after": [{"type": "note", "text": "と物狂しながら…"}, {"type": "speech", "speaker": "狂女", "text": "それは兎もあれ…"}],
     "note": "理由"}]
   ```
   `find` はその段のその欄で 1 か所だけに当たる文字列。`set` で欄を置き換え、`item` で発言ごと置き換え（ト書きを本文と読んだ所など）、`delete` で崩れだけの行を除き、`after` の発言を後ろに足す。
   これまでの差し替え（2026-11-10）：隅田川 p1525（通釈の崩れと読み落とし）、淸經 p846（地下歌・上歌がツレの発言につながっていた）、蟻通 p220（通釈の崩れ・「……」の読み落とし）・p224（ト書きを本文と読んだ）、道成寺 p1803（同）、船辨慶 p2779（通釈の崩れ）。
4. **梗概を全文照合したら印を書く**:
   ```
   p1857	（梗概）	（梗概）	梗概を原本の画像と全文照合済み（日付）
   ```
   曲データの `check.summary` が「確認済み」になり、サイトの梗概の見出しに「原本と照合済み」と出る。印がない曲は「未検証」と出る。
5. **公開の基準**:
   - これから載せる曲は、梗概の全文照合（4 の印）まで済ませてから載せる。梗概は短く（1 曲 300〜500 字）、読者の入口なので最優先。
   - 人物欄は 1・2 で拾ったものを確かめる。
   - 通釈・ト書き・間狂言は全文の照合ができないので、1〜3（固有名詞と拾った箇所）を済ませて載せ、凡例と曲ページの注記で「OCR のまま」と示す。
   - すでに載せている 25 曲は、梗概の照合を順に進める（済んでいない曲は「未検証」と出る）。

背景: 旧字・異体字の正誤は制作者本人でも判定が難しいので、「意味と文脈からの一字判定＋原本照合」を標準にし、手順の側で担保する（2026-11-10 本人の意向）。

### 異体字・互換漢字の扱い（決めること）

- 方針は「印刷どおり」。淸／清 のように形の違う字が混ざるときは、印刷が混ざっているのか OCR の誤りなのかを画像で確かめる（印刷が淸なら淸に直す）。
- 見た目が同じで文字コードだけ違う字（互換漢字。海 U+FA45、神 U+FA19、僧 U+FA31 など）は、OCR がそのまま出したもの。検索・照合で別の字になるので、サイト用データでは通常の字（NFC）にそろえる案がある。そろえるかどうか、いつそろえるかは未決（`info_check.py` が曲ごとの種類を出す）。

## 判定の注意

- 曲名は大観の表記（旧字）: 船辨慶・淸經・錦戶 など。`data/yokyoku/taikan_toc.json` の title。
- 間違えやすい字: 鳥/烏、遺/遣、間/問、葉/菜/集、荼/茶、憍/橋、九/丸、真言（梵語の音写）の難字。
- 行をまたぐ小字の括弧（ト書き）の開きを「ハ」などと読むことがある → 括弧に直す。
- 欄外のゴミ（数字・「パンプ」など）は「正」を空にして削除扱い。
- OCR の字が互換漢字のことがある（例: 神 U+FA19）。訂正が当たらないときは字のコードを確かめ、OCR の字のまま書く。
- シートに出ない行も、行を画像で見たいときは `~/tools/textvenv/bin/python scripts/crop_lines.py <曲名> <出力.jpg> <文字列…>` で切り出せる。
- 「中入」の後に散文がない曲（藍染川の入水など）は、間狂言の欄を出さない（build_kyoku.py が判断）。
- 見開きの継ぎ目に印刷された段の印は左右両方の頁から拾われるが、build_kyoku.py が一つにまとめる（蟻通【五】）。
- 安達原 p119 の真言は「吒干鋡」がはっきり読める（葵上・道成寺の要再確認の参考に）。
- 通釈の話し手名も OCR で誤ることがある（運生→蓮生、賞之→貫之、明→男 など）。曲データの通釈の話し手の一覧を見て、数の少ない名前を疑う。訂正は `p頁\t運生「いかにも\t蓮生「いかにも` のように後ろの数字まで含めて書く（本文に当たらないように）。
- この照合で拾えない誤り: 半魚文庫がかなで書く所をOCRが別の漢字に誤読した場合（表記の違いとして流れる）。

| `scripts/info_check.py` | 梗概・人物・通釈の話し手名の誤りの疑いを拾う（同じ曲のほかの所との食い違い） |
| `scripts/check_status.py` | 進み具合 |
| `scripts/crop_lines.py` | 文字列で探した行を原本画像から切り出す |

`collate.py` と `make_checks.py` は `~/tools/textvenv/bin/python`（pykakasi・Pillow 入り）で動かす。

## あとでやること

- 一致率の低い曲（翁・猩々・吉野天人など）は半魚文庫と詞章の形が違う。構造を別に確認する。
- 仕分けが block（60 字超の挿入。間狂言の混入など）のものを構造として確認する。
- 「要再確認」（道成寺・葵上・船辨慶の真言の荼/茶・鋡など）を高解像度で見直す。
- 切り出しの構造の問題（高砂・安宅・阿漕で確認。文字の誤りとは別）:
  - 同じ行が 2 回出ることがある。片方は `〔?〕` 付きで崩れ（2 行の混ざりなど）、もう片方は正しいが `＊`（ト書き）扱いになっている。崩れた行は fixes で削除扱いにした。
  - 本文の大字の行がまとめて `＊` になっている所がある（高砂 p1869–1872、安宅 p94 付近）。
  - ト書き（装束の説明など）が本文扱いのまま残る所がある（隅田川 p1533）。
  - 船辨慶 p2781（間狂言の頁）は読み取り全体が崩れている。
- 全曲が済んだら、訂正を反映して公開用の本文データを作る。
- 既に書き起こした通釈 6 曲（清経・竜田・阿漕・高砂・羽衣・敦盛）を、OCR の通釈と突き合わせる。
