# 凡例

このリーダーの本文・通釈・曲情報は、佐成謙太郎『謡曲大観』（明治書院 1930–31）の印刷面を、国立国会図書館デジタルコレクションの画像から文字に起こしたものです。
ここでは、どのように文字に起こし、どこまで確認したかを記録します。

## 要点

- 文字起こしは、OCR（画像から文字を読み取るソフト）で機械的に行いました。記憶や推測で文字を補ったところはありません。直した字は、すべて原本の画像で確かめたものです。
- 確認は、別の版である半魚文庫「謡曲三百五十番集」の本文と自動で照らし合わせ、**食い違った箇所だけ**を原本の画像で見比べる方法で行いました。
- そのため、確認済みの曲でも「全文を一字ずつ校正した」状態ではありません。誤りが残っている可能性があります。各段と曲情報の下に原本画像へのリンクがあるので、気になる箇所は原本で確かめてください。
- このリーダーには、本文の確認が済んだ曲だけを載せています。

## 底本

| 項目 | 内容 |
|---|---|
| 書名 | 佐成謙太郎『謡曲大観』第一巻〜第五巻・別巻（明治書院、1930–31） |
| 画像 | 国立国会図書館デジタルコレクション（[第一巻](https://dl.ndl.go.jp/pid/1884298)・[第二巻](https://dl.ndl.go.jp/pid/1884307)・[第三巻](https://dl.ndl.go.jp/pid/1884321)・[第四巻](https://dl.ndl.go.jp/pid/1884333)・[第五巻](https://dl.ndl.go.jp/pid/1884343)・[別巻](https://dl.ndl.go.jp/pid/1884352)） |
| 権利 | パブリックドメイン（著者 1966 年没。デジタルコレクションの表示は「保護期間満了」） |

大観の各ページは、上段が頭注（語釈）、中段が本文（謡の詞章）、下段が通釈（現代語訳）の3段組です。このリーダーでは中段と下段を使います。
曲名の下の曲情報（能柄・人物・所・時・流派・梗概）は、各曲の前にある解説のページから取っています。
曲名の検索に使う読み仮名は、このリーダーで現代仮名遣いで付けています（大観の解説ページの曲名にも小さなルビがありますが、OCR では読み取れないため使っていません）。読みは、国立国会図書館サーチの書誌データで、謡本（檜書店・わんや書店）の書名に付けられた読みと照らし合わせて確かめました。
本巻（第一〜五巻）に能 236 曲、別巻に闌曲・曲舞（謡の聞かせどころを独立させた短い謡物）46 編が入っています。

## 作業の流れ

### 1. OCR で文字を読み取る

- 第一巻〜第五巻と別巻の謡曲のページ（約 3,700 ページ）を、国立国会図書館が公開している OCR ソフト [NDLOCR-Lite](https://github.com/ndl-lab/ndlocr-lite)（CC BY 4.0）で読み取りました。
- 見開きの画像を左右のページに分けてから読み取っています。分けるときに継ぎ目を少し重ねているので、継ぎ目の行が二重に読み取られたものは除きました。
- 旧字・歴史的仮名遣いは、印刷どおりに読み取られたものをそのまま使います。新字や現代仮名遣いには直していません。

### 2. 曲ごと・段ごとに分ける

- 目次の開始ページをもとに、ページを曲ごとに分けました。別巻は 1 ページに 2 編がまたがることがあるので、曲名の見出しの位置で区切りました。
- 各行の位置から、頭注・本文・通釈のどの段かを判定しました。
- 曲末の〔考異〕（諸流の異同の欄）は除いています。
- **段**（【一】【二】…）：段の印は、頭注・本文・通釈の 3 段のほぼ同じ位置に印刷されています。3 段の印を位置でまとめ、読み取れた番号で多数決をとって区切りました。印が読み誤られていても（【二】を【三】と読むなど）、ほかの段の印で補えます。どの段でも読み落とされた印は、原本で位置を確かめて補いました。見開きの継ぎ目に印刷された印は左右両方のページから読み取られるので、一つにまとめています。
- **本文のト書き**：型付（所作の説明）などのト書きは、本文より一段下げて印刷されています。その位置で本文と見分けました。
- **通釈の地の文**：通釈のうち、所作や場面の説明は小さい字で印刷されています。1 字あたりの大きさ（行の長さ÷字数）で見分け、このリーダーでも小さい字で表示しています。
- **役名**：本文の行頭の役名（シテ・ワキ・地など）を取り出しました。小字で小段名の上に並べて印刷された役名（「シテ／ツレ」など）は「シテ・ツレ」と表記しています。役名が印刷されていない小段は、前の役の続きとして色分けしています。
- **通釈の台詞と場面の見出し**：通釈は「話し手「台詞」」の形と地の文でできています。括弧の対応で台詞の終わりを決めていますが、OCR が閉じ括弧を読み落とすことがあるので、次の行が別の話し手で始まるときや、小さい字の説明に変わるときにも台詞を区切ります。場面の見出し（夢幻能の「前段」「後段」、劇能の「第一段」「第二段」）は見出しとして表示しています。
- **間狂言**：本文・通釈の段をまたぐ長い行で組まれているので、中入（または【間】の印）から次の段の印までを、元の OCR からまとめて取り出しました。大観の間狂言には通釈がないので、通釈の欄は空です。中入の後に間狂言のない曲（藍染川の入水の場面など）では、間狂言の欄を出していません。
- **曲情報**：解説のページの【能柄】【人物】などの見出しで区切って取り出しました。見出しが読み誤られることがある（【梗概】を【裸紙】と読むなど）ので、見出しの並び順からも補っています。

### 3. 半魚文庫の本文と照らし合わせる

- 大観の本文（OCR 結果）と半魚文庫の本文を、どちらも**読み（ひらがな）**に直してから比べました。
- こうすると、次のような単なる表記の違いは、食い違いとして数えません。
  - 漢字とかなの書き分け（「是」と「これ」など）
  - 旧字と新字
  - 句読点や踊り字（〳〵など）
- さらに、次のような違いも自動で除きました。
  - 送り仮名の違い（「恨」と「恨み」など）
  - 繰り返しの書き方の違い（大観は繰り返しを全部書き、半魚文庫は省くことがある）
  - 役名やト書きが混ざったもの
- 残った食い違いを「要確認」としました。1 曲あたり 30 か所前後で、全体では約 7,700 か所です。
- 役名も、同じように半魚文庫の同じ箇所の役名と照らし合わせました。食い違ったもの、読めなかったもの、崩れて前の発言につながったものを「要確認」としました。

半魚文庫の本文は、この照らし合わせにだけ使っています。このリーダーには収録していません。

### 4. 原本の画像で見比べる

- 要確認の箇所ごとに、該当する行を原本画像から切り出して並べ、印刷された字と OCR の結果を見比べました。
- 判定の基準は次のとおりです。

| 原本画像の字 | 判定 | 対応 |
|---|---|---|
| OCR と違う | OCR の誤り | 印刷どおりに直し、記録する |
| OCR と同じ | 大観と半魚文庫の版の違い | 直さない（大観の表記を残す）。役名は「直さない」と判定したことも記録する |
| 小さく判別しにくい | 保留 | 「要再確認」として記録し、高解像度の画像で見直す |

- 例：印刷は「時鳥」、OCR は「時烏」 → OCR の誤りとして「時鳥」に直す。
- 例：大観は「少女」、半魚文庫は「乙女」 → 版の違いなので、大観の「少女」のまま。
- 例：役名が、大観は「強力」、半魚文庫は「シテ」 → 版の違いなので、大観の「強力」のまま。

この見比べは、画像を読み取れる AI（Claude）が行いました。判定は、すべて曲ごとの記録（ページ・OCR の字・正しい字・備考）に残しています。記録は [GitHub のリポジトリ](https://github.com/torunishijima/yokyoku-reader)の `work/fixes/` にあります。

## 確認の範囲と限界

この方法で見つけられるのは、**本文の OCR の結果が半魚文庫と食い違った箇所の誤り**です。次のものは確認していません。

- OCR と半魚文庫が、たまたま同じ字で一致している箇所の誤り（照らし合わせで一致したため、画像を見ていない）。
- 半魚文庫がかなで書いている語を、OCR が別の漢字に読み違えた場合（表記の違いとして除かれる）。
- 通釈（下段）の文字の誤り。通釈は半魚文庫に対応するものがありません。ただし話し手の名前の明らかな読み誤り（「蓮生」を「運生」と読むなど）は、気づいたものを前後の文脈や原本で確かめて直しています。
- ト書き（型付・所作の説明）の文字の誤り。ト書きは半魚文庫にありません。
- 曲情報（能柄・人物・所・時・流派・梗概）の文字の誤り。解説のページから OCR のまま取っています。曲情報の下のリンクから原本の解説ページを開けます。
- 間狂言の文字の誤り。半魚文庫には間狂言の詞章がほとんどないため、照らし合わせができません。このリーダーでも「OCR のまま」と断って表示しています。行がまるごと読み落とされたり、崩れて読まれたりしている箇所があります。
- 半魚文庫に収録されていない別巻の 8 編（起請文・願書・勸進帳と、本巻の能と同名の 5 編）。これらは大観でも通釈が省略されています。

また、次の点にも注意してください。

- 本文とト書きの境目、通釈の字の大きさ、行の順番は、画像上の位置や大きさから機械的に判定しています。一部を原本と見比べて確かめましたが、すべてではありません。
- 段の区切りは、本文と通釈の分量の釣り合いで大きなずれがないことを確かめています。段の境目が発言 1 つ分ずれる程度のものは、この点検では見つかりません。
- 詞章の形が半魚文庫と大きく異なる曲（翁など）は、照らし合わせがうまく働きにくい部分があります。

## 確認の進み具合

確認は曲ごとに順次進めています（2026-11-09 時点で、照合できた 274 曲中 25 曲）。
確認した 25 曲では、本文の要確認 929 か所と役名の要確認を原本で見比べ、343 件を記録しました。うち 290 件は OCR の誤りや段の印の読み落としなどを直したもの（通釈の話し手名などの直し 53 件を含む）、残りの 53 件は「直さない」と判定した役名などの記録です。
字が小さく判別できず、高解像度の画像で見直す予定の箇所が 6 件あります（道成寺・葵上・船辨慶・安達原の真言）。

- 誤りの例：鷗→鴫、箜篌→笠溪、芭蕉葉→芭蕉菜、光の間→問、遺→遣、東→束、無益→無盆、娑婆→婆婆、嬋娟→婢娼、薩埵→薩唾、抖擻→抖撤、閧→関
- 道成寺・葵上の真言のように難しい字が多い部分では、誤りがまとまって出ています。
- 役名の誤りの例：ッキ→ワキ、ッシ→ツレ、び→シテ、興→地。小字で印刷された役名（「シテ／ツレ」など）は、読み落とされることが多くありました。

## 使ったソフト

| ソフト | 用途 | ライセンス |
|---|---|---|
| [NDLOCR-Lite](https://github.com/ndl-lab/ndlocr-lite)（国立国会図書館） | 画像からの文字の読み取り | CC BY 4.0 |
| [pykakasi](https://codeberg.org/miurahr/pykakasi) | 照らし合わせのための読み（ひらがな）への変換 | GPL-3.0-or-later |
| Python 標準ライブラリ difflib | 文字列の比較 | PSF |
| Claude（Anthropic） | 原本画像との見比べ | — |

作業に使ったスクリプトは [GitHub のリポジトリ](https://github.com/torunishijima/yokyoku-reader)の `scripts/` にあります。

| スクリプト | 役割 |
|---|---|
| `ndlocr_all.py` | 全ページの OCR |
| `split_taikan.py` | 曲ごと・段（頭注・本文・通釈）ごとの切り出し |
| `collate.py` | 半魚文庫の本文との照らし合わせ |
| `make_checks.py` | 本文の要確認箇所を原本画像から切り出す |
| `crop_lines.py` | 指定した行を原本画像から切り出す（要確認に出ない箇所を確かめる） |
| `role_check.py` | 役名の照らし合わせと、要確認箇所の切り出し |
| `build_kyoku.py` | 訂正を当てて、段・役名・ト書きを整え、このリーダーのデータを作る |
| `build_index.py` | 曲の一覧を作る |
| `fetch_yomi.py` | 曲名の読みを国立国会図書館サーチの書誌データから集める |
