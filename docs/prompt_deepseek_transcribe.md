# 謡曲大観 書き起こしプロンプト（DeepSeek 用）

画像1枚（見開きの片ページ）ごとに、このプロンプトと画像を渡す。
画像は国立国会図書館デジタルコレクションの IIIF から取得する（`scripts/taikan_pages.sh` などで1ページずつ切り出したもの）。

---

## プロンプト本文

あなたは、昭和初期に刊行された活字本の画像を、正確に文字に起こす係です。
画像は、佐成謙太郎『謡曲大観』（明治書院、1930–31年）の1ページです。縦書きで、右の行から左の行へ読みます。

### ページの構成

ページは横線で上・中・下の3段に分かれています。

- 上段：頭注（小さい字の語釈。「○」で始まる）
- 中段：本文（謡曲の詞章。大きい字にふりがな付き。行頭に「シテ」「ワキ」「地」などの役名がある）
- 下段：通釈（現代語訳。行頭に「淸經」「妻」などの人物名がある）

指示された段だけを書き起こしてください。今回の対象は【{中段の本文 / 下段の通釈}】です。

### 書き起こしの規則

1. **見えるとおりに写す。** 旧字（經・歸・髮など）、歴史的仮名遣い（思ふ・ゐる・ゑなど）、句読点（。、）は画像のとおりにする。新字や現代仮名遣いに直さない。
2. **ふりがなは書かない。** 漢字の右に付いた小さな読みがなは省く。本文中に仮名で書かれた語は、仮名のまま書く。
3. **踊り字。** くの字点（縦に長い「く」の形）は「〳〵」、濁点付きは「〴〵」と書く。「ゝ」「ゞ」「々」は画像のとおりに書く。
4. **役名・人物名。** 行頭の役名（シテ・ワキ・ツレ・地・地上歌・シテサシ など）や、通釈の人物名（淸經・妻・淡津 など）は、行の先頭に書き、そのあとにタブを1つ入れて続ける。かぎ括弧「 」『 』の開き記号は書かない。
5. **小さい字の注記。** 本文や通釈の行間にある小さい字の所作の説明（例：「と守袋を扇にのせて…」「地取に笠を脱ぎて正面に向き、」「〔中舞〕」）は、行頭に「＊」を付けて別の行に書く。本文中の丸括弧の小字（例：「（と守袋を下に置き）」）も同じく「＊」の行に分けて書く。
6. **段の見出し。** 【一】【二】のような見出しがあれば、そのまま1行で書く。「前段」「後段」の見出しも1行で書く。
7. **読めない字。** 判読できない字は「〓」1字で置き換える。推測で埋めない。判読に自信がない字は、その字の直後に「〔?〕」を付ける。
8. **補わない・直さない。** ページの端で切れている語や文は、切れたまま書く。前後のページや、あなたが知っている謡曲の詞章で補ったり、誤植と思っても直したりしない。この作業は、他の版との照合に使うため、**画像に写っている文字だけ**が必要です。
9. **余計なものを書かない。** ページ番号、柱（欄外の曲名）、隣のページの写り込み、説明や感想は書かない。出力は書き起こしだけにする。

### 出力の例（中段の本文の場合）

```
【一】
ワキ次第	八重の潮路の浦の波。八重の潮路の浦波九重にいざや歸らん
＊地取に笠を脱ぎて正面に向き、
ワキ	これは左中將淸經の御内に仕へ申す。淡津の三郎と申す者にて候。
```

```
＊と次第に旅の目的を述べ、
```
