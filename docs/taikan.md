# 謡曲大観 通釈データ

佐成謙太郎『謡曲大観』（明治書院 1930–31、全7冊）の通釈（各ページ下段の現代語訳）を書き起こしたもの。

- 権利：パブリックドメイン（著者 1890–1966 没。NDL デジタルコレクションの著作権表示 pdm、インターネット公開）
- 画像：国立国会図書館デジタルコレクション
  - 首巻 1884285 / 第一巻 あ–か 1884298 / 第二巻 か–し 1884307 / 第三巻 し–て 1884321 / 第四巻 1884333 / 第五巻 1884343 / 別巻 1884352
  - IIIF：`https://dl.ndl.go.jp/api/iiif/<pid>/R<7桁コマ番号>/<region>/<size>/0/default.jpg`
  - 1コマ＝見開き2ページ（左が奇数ページ）
- 書き起こし：Claude が画像から読み取り。**未校正**。各段の `page` から原本ページに当たって確認できる。
- 旧字・歴史的仮名遣いは原本のまま。

## ファイル形式（`data/yokyoku/taikan/<曲名>.json`）

- `dan[]`：謡曲大観の段（【一】【二】…）単位
  - `hangyo_anchor`：半魚文庫原文（`hangyo/<file>`）でこの段が始まる位置の文字列。原文側をここで区切って通釈と並べる
  - `items[]`：`speech`（話者付き）/ `note`（小字のト書き）/ `gloss`（歌の通釈の括弧書き）/ `narration`（話者なしの地の文）
- `text_issues[]`：半魚文庫原文と謡曲大観本文の異同。原文は改変せず記録のみ
